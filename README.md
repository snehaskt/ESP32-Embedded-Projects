# ESP32 Embedded Projects

A collection of embedded development projects using ESP32 and ESP-IDF.

## Development Environment

- Controller: ESP32-WROOM-32
- Framework: ESP-IDF v5.2.2
- IDE: Visual Studio Code
- Operating System: Ubuntu 22.04 LTS
- Language: Embedded C

## Projects

| Project | Description | Status |
|---|---|---|
| 01_hello_world | First ESP-IDF application | Completed |
| 03_bme680 | BME680 sensor library integration | In Progress |

## Learning Topics

- ESP-IDF project structure
- GPIO and peripheral interfacing
- FreeRTOS
- I2C and SPI
- Wi-Fi and networking
- HTTP Server
- OTA firmware updates
- MQTT and AWS IoT
